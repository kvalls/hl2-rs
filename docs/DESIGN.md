# Design

## Goal and architecture

Reconstruct HL2 in Rust using owned content. No host-game transport or Valve DLL dependency. Native analysis/databases stay private; public source contains original implementation and permitted third-party resources.

Owned VPK/loose/map content -> source-assets bounded decoders -> modkit-core contracts/player/pose math -> hl2-simulation gameplay/choreography/Rapier -> Bevy or retained presentation. hl2-ui records CPU draw commands for both hosts. Setup or asynchronous transitions load resources; frame systems consume prepared data.

AGENTS.md records fixed-step order and renderer invariants. Bevy uses custom materials/lightmaps, separate sky/world/viewmodel/HUD cameras, GPU skinning/current bounds and player/monitor PVS/frustum rejection. Identical material/lightmap pairs share handles. Spatial splitting remains off by default. Replacing Rapier is a separate behavior migration.

8a. Retail review done 2026-10-07 (private lighting-20261007/README.md, engine.dll). Default r_radiosity 4: a non-static-prop entity's ambient cube comes from Mod_LeafAmbientColorAtPos (samples of its leaf, weight 1/(d^2+1), linear RGBExp32). World lights flagged DWL_FLAGS_INAMBIENTCUBE are skipped when that leaf ambient is used. Other lights get ratio = falloff x lightstyle x visibility, where visibility is a world-only trace that tolerates up to 8 units of blockage. A light is kept as one of r_worldlights=4 local lights when it is a surface light or its luminance x ratio >= r_worldlightmin (0.0002); the weakest kept light is evicted. Lights that are not kept are added to the cube with per-axis max(dot, 0) weighting. At draw time, models flagged with STUDIOHDR_FLAGS_AMBIENT_BOOST get the boost: if the cube average is below 0.3 and below 0.1 x direct luminance, the cube is scaled by min(5, 0.1 x direct / max face). Light-to-shader conversion: surface lights become spots with 1/d^2, point lights stay points, spots keep their cone and exponent, the skylight becomes directional, and quake/skyambient lights are dropped. The shader follows SDK common_vs_fxc.h.
